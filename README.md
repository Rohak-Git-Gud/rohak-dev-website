# My Personal Website

Welcome to the source code of my personal website.

This site acts as my digital resume, project showcase and a personal blog where I share my thoughts and write-ups. It is designed to be highly responsive, accessible and fast.

## Tech Stack

- **Language and Framework**: TypeScript v5 and Next.js v16 (App Router).
- **Styling and Animations**: Tailwind CSS v4, Shadcn UI and Framer Motion.
- **Blog Engine**: next-mdx-remote & gray-matter.

## Want to build your own?

If you like the design and architecture of this site and want to use it for yourself, I have created a generic, data-cleared version of this codebase specifically designed for easy forking and customization.

**Head over to the [template repository](https://github.com/Rohak-Git-Gud/dev-website-template)** and check out the [TEMPLATE_GUIDE.md](https://github.com/Rohak-Git-Gud/dev-website-template/blob/main/TEMPLATE_GUIDE.md) for a step-by-step tutorial on how to configure, populate and deploy your own version. Run the following commands:

```bash
npm install
npm run dev
```

Open [http://localhost:8126](http://localhost:8126) with your browser to see the site.  
_**Note:** The default port is 3000, but I have changed it to 8126 for this project.  
To change the port, please edit the `package.json` file's `scripts.dev` property._
